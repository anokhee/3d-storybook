# Object Catalog

I'm building this catalog of stylized 3D objects in Three.js. I feel most
comfortable writing objects in code rather than hand-modeling them, because
coding them produces a very particular, noticeable style: almost symmetrical
and clay-like, but still a little whimsical and weird.

The objects are modular and swappable, and can be combined in funny ways,
which I enjoy. It's like digital Legos. It's a relaxing project. Everything
can be exported as a .glb and reused in a game engine like Unreal or Godot,
but for now I find it most comfortable to build and tweak the assets in this
little collection I'm hosting online.
