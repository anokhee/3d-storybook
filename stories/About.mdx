# An object library

Every 3D object I have made, taken out of the project it was built for and
stood on its own so it can be turned over, recoloured and resized.

Pick an object in the sidebar. The **Controls** panel below the viewport
edits it live; the named variants under each object are presets worth seeing.
Drag to orbit, scroll to zoom.

## Projects

- **Wooden Dollies** — a small planet of clay furniture, trees and machines.
  React Three Fiber components, each with a parameter file naming every
  dimension and colour.

Built by Anokhee Jandhyala.
