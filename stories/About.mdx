# An object catalog

Every 3D object I have made, taken out of the project it was built for and
stood on its own so it can be turned over, recolored and resized.

Pick an object in the sidebar. Drag to orbit, scroll to zoom. The
lightbulb in the toolbar shows each one under the Wooden Dollies toon light
or the albatross flat light; the slider beside it runs the day from night
to noon. Some objects have **Controls** on the right for their colors and
sizes.

Built by Anokhee Jandhyala.
